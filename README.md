# BlackSMS

**Your Messages. Your Rules.**  
**پیام‌های تو، قوانین تو.**

BlackSMS is a privacy-focused Android SMS application designed to give users control over unwanted messages through intelligent filtering, adaptive learning, sender blocking, and customizable rules.

بلک‌اس‌ام‌اس یک اپلیکیشن پیامک اندرویدی با تمرکز بر حریم خصوصی است که با فیلتر هوشمند، یادگیری تطبیقی، مسدودسازی فرستندگان و قوانین قابل تنظیم، کنترل پیام‌های ناخواسته را در اختیار کاربر قرار می‌دهد.

## Features | قابلیت‌ها

- **Smart Spam Filtering | فیلتر هوشمند اسپم:** Identify and filter suspicious and unwanted SMS messages.
- **Adaptive Learning | یادگیری تطبیقی:** Learn from messages and senders blocked by the user, recognize similar patterns in incoming messages, and predict unwanted SMS. Based on confidence and user settings, messages can be automatically blocked or quarantined. User feedback helps refine future filtering.
- **Sender Blocking | مسدودسازی فرستنده:** Block unwanted phone numbers, sender IDs, and non-standard senders.
- **Custom Rules | قوانین شخصی:** Create custom keyword and pattern-based filtering rules.
- **Message Quarantine | قرنطینه پیام‌ها:** Separate filtered messages from the regular inbox for review and management.
- **Privacy-Focused | حفظ حریم خصوصی:** Prioritize local processing and minimize unnecessary data handling.
- **Native Android | اندروید بومی:** Built with Kotlin for Android.

## Technology | فناوری

- Kotlin
- Android SDK
- Native Android

## Privacy | حریم خصوصی

Privacy is a core design principle. BlackSMS is designed to process message data locally whenever possible and avoid unnecessary collection or sharing of personal information.

حریم خصوصی یکی از اصول اصلی پروژه است. BlackSMS به‌گونه‌ای طراحی شده که پردازش پیام‌ها تا حد امکان روی دستگاه انجام شود و از جمع‌آوری یا اشتراک‌گذاری غیرضروری اطلاعات شخصی جلوگیری کند.
